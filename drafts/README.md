# Draft test data

Student drafts written against assignments in `samples/`, used to measure
whether the evaluator's verdicts are any good.

Naming: `<sample-name>--<quality>.txt`

Each draft is written to produce **known** verdicts, so a run can be scored
rather than eyeballed. Intended verdicts live in `drafts/expected.json`,
indexed by the goal order THE WORK came back in.
